The Note for Templates developer and Users
0.01:
This was the first version of the project, then called PygameTools.
In the kernel, Margin was included, and an SFM template was added to create smart screens with integrated Margin.
0.02:
- Added class LayoutHelper (formerly Next) in kernel
Improved Margin class
New templates:
    VerticalStack
    HorizontalStack
Kernel initialization is now automatic via kernal_Init (no need to call pygame.init() manually when using templates).
SFM renamed to MarginScreen
0.03:
Optimized kernel performance (Margin, LayoutHelper) – now only 1.1–1.3× slower than equivalent manual code.
Added SunLayout template – places objects in a 3×3 grid around a central object.
Updated DeveloperRule.txt with guidelines for template documentation and advanced versions.
This project changes its public name to **PGT** (Pygame Tools) for brevity.
0.04:
Added geometry.py to kernel (vector, point, angle, rect utilities).
Added SimpleDraw template (basic drawing wrapper).
Added MissPoint template (missing‑point calculator).
Updated all template .md files to the new concise format.
0.05:
Added AroundLayoutPro (extended Sun) with circle layout, screen‑edge positioning, alignment fixing.
Extended geometry.py with Pythagorean, law of cosines, triangle area, point‑line distance.
0.06:
Added Grid kernel (basic N×M grid layout support).
Added VideoResize template (automatic resize detection and propagation).
0.07:
Added ProHorizontalStack and ProVerticalStack with auto‑wrap and padding shrink.
Completed the testing phase (v0.01 - v0.07).
